Sukebei Preview 插件测试页面

测试说明

此页面用于测试 Sukebei Preview Chrome 插件的功能。由于插件设计为在 sukebei.nyaa.si 网站上运行，您需要按照以下步骤进行测试：

  1. 安装插件（按照 README.md 中的说明）
  2. 修改插件的 manifest.json 文件，添加此测试页面到 matches 列表中
  3. 重新加载插件
  4. 在此页面上测试功能

如何修改 manifest.json

打开 manifest.json 文件，找到 content_scripts 部分，将 matches 数组修改为：


"matches": [
    "*://sukebei.nyaa.si/*",
    "file:///*test_page.html"
]

这将允许插件在本地测试页面上运行。

注意： 在实际使用时，您应该将 matches 恢复为原始设置，只包含 "*://sukebei.nyaa.si/*"。

测试链接

以下是一些模拟的链接，用于测试插件功能。将鼠标悬停在这些链接上，应该会显示预览窗口（如果插件正确配置）：

https://sukebei.nyaa.si/view/1234567 - 测试链接 1 https://sukebei.nyaa.si/view/7654321 - 测试链接 2 https://sukebei.nyaa.si/view/9876543 - 测试链接 3 这个链接不应该触发预览（不是 /view/ 链接） 这个链接也不应该触发预览（不是 sukebei.nyaa.si 域名）

预期行为

  • 当鼠标悬停在以 "https://sukebei.nyaa.si/view/" 开头的链接上时，应该会出现预览窗口
  • 预览窗口应该显示在鼠标附近
  • 当鼠标移开链接时，预览窗口应该消失
  • 对于不符合条件的链接，不应该显示预览窗口

注意： 在本地测试页面上，插件可能无法获取实际的页面内容，因为浏览器的安全策略可能会阻止跨域请求。在实际的 sukebei.nyaa.si 网站上使用时，这个问题不会出现。

故障排除

如果预览功能不工作，请检查：

  1. 插件是否已正确安装并启用
  2. manifest.json 是否已正确修改以包含测试页面
  3. 浏览器控制台是否有任何错误消息（按 F12 打开开发者工具）
