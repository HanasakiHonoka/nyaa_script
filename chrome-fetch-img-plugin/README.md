# Sukebei Preview Chrome插件

这是一个Chrome浏览器插件，当用户访问sukebei.nyaa.si网站时，鼠标悬停在以"https://sukebei.nyaa.si/view/"开头的链接上，插件会自动请求该链接指向的页面内容，并在鼠标附近显示一个悬浮窗口来展示这些内容，包括封面图片（如果有）。

## 功能特点

- 在sukebei.nyaa.si网站上自动检测有效链接
- 鼠标悬停时获取链接内容
- 在鼠标附近显示悬浮预览窗口
- 自动提取并显示hentai-covers.site的封面图片（如果描述中包含）
- 如果没有封面图片，则显示页面的主要内容（标题、信息表格、描述等）
- 使用本地缓存存储图片URL，减少重复请求
- 自动清理过期缓存（3天）
- 鼠标移开时自动隐藏预览窗口

## 安装方法

### 1. 准备图标文件（忽略）

在安装插件之前，您需要准备图标文件：

1. 在项目根目录创建`images`文件夹（如果不存在）
2. 准备三个尺寸的图标文件：
   - 16x16像素 - 保存为`images/icon16.png`
   - 48x48像素 - 保存为`images/icon48.png`
   - 128x128像素 - 保存为`images/icon128.png`

您可以使用项目中的`icon_generator.html`工具来生成这些图标：
1. 打开`icon_generator.html`文件
2. 选择您喜欢的颜色
3. 点击"生成图标"按钮
4. 下载生成的三个图标文件
5. 将这些图标文件保存到项目的`images`文件夹中

### 2. 安装插件

1. 打开Chrome浏览器
2. 在地址栏中输入`chrome://extensions/`并按回车
3. 在右上角启用"开发者模式"
4. 点击"加载已解压的扩展程序"按钮
5. 选择nyaa-fetch-img-plugin.zip
6. 插件应该会出现在您的扩展程序列表中

## 使用方法

1. 安装插件后，访问sukebei.nyaa.si网站
2. 将鼠标悬停在任何以"https://sukebei.nyaa.si/view/"开头的链接上
3. 稍等片刻（约300毫秒），预览窗口将会出现，显示链接指向的页面内容
4. 如果页面描述中包含hentai-covers.site的链接，插件会自动提取并显示封面图片
5. 如果没有封面图片，插件会显示页面的主要内容（标题、信息表格、描述等）
6. 移开鼠标，预览窗口将自动隐藏

## 文件结构

- `manifest.json` - 插件的配置文件
- `content.js` - 内容脚本，处理鼠标事件、页面内容获取和预览显示
- `background.js` - 后台脚本，处理跨域请求
- `cache.js` - 缓存管理模块，处理图片URL的缓存存储和检索
- `styles.css` - 样式文件，定义预览窗口的外观
- `images/` - 包含插件图标的文件夹
  - `icon16.png` - 16x16像素的图标
  - `icon48.png` - 48x48像素的图标
  - `icon128.png` - 128x128像素的图标
- `icon_generator.html` - 用于生成插件图标的工具
- `README.md` - 本文档

## 技术细节

### 缓存机制

插件使用Chrome的`storage.local` API来缓存图片URL，减少重复请求：

- 缓存项包含页面URL、图片URL和时间戳
- 缓存有效期为3天
- 每次访问缓存项时会更新时间戳
- 页面加载时会自动清理过期缓存

### 跨域请求

插件使用后台脚本（background.js）来处理跨域请求，避免内容脚本的同源策略限制：

- 内容脚本通过`chrome.runtime.sendMessage`发送请求
- 后台脚本使用`fetch` API获取页面内容
- 后台脚本将获取的内容返回给内容脚本

### 图片提取

插件使用以下步骤提取封面图片：

1. 获取页面内容
2. 解析HTML
3. 提取描述元素
4. 从描述中提取hentai-covers.site链接
5. 获取封面页面内容
6. 从封面页面中提取图片URL
7. 缓存图片URL
8. 显示图片

## 自定义

您可以通过修改以下文件来自定义插件的行为和外观：

- `content.js` - 修改预览窗口的行为，如悬停延迟时间、内容提取逻辑等
- `styles.css` - 修改预览窗口的样式，如大小、颜色、边框等
- `cache.js` - 修改缓存机制，如缓存有效期等

## 注意事项

- 此插件仅在sukebei.nyaa.si网站上运行
- 预览功能可能受到网站结构变化的影响，如果网站更新了页面结构，可能需要更新内容提取逻辑
- 请遵守网站的使用条款和政策

## 隐私声明

此插件不会收集或传输任何个人数据。它只会在您访问sukebei.nyaa.si网站时，获取您悬停的链接内容用于预览显示。所有数据都存储在您的本地浏览器中，不会发送到任何第三方服务器。
